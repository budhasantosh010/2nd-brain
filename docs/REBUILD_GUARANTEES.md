# Rebuild Guarantees

Generated SQLite, FTS and vector state may be deleted and rebuilt. Canonical truth is raw preserved sources, canonical Markdown and durable resolution/project/gap ledgers. Raw provider extraction is evidence input, not resolved truth.

Before rebuilding an older Phase 1/2 database, the migration step materializes missing canonical-resolution, project-history and gap-history ledgers without rewriting raw sources or canonical Markdown. Existing Phase 2.5 ledgers remain authoritative. Rebuild preserves canonical concept IDs, approved updates, duplicate decisions, conflicts, supersession, relationships, project history/current state, gaps, provenance and retrieval/index metadata.
