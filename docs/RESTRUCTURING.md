# Restructuring

The structural analyzer detects semantic duplicate candidates, orphan/weak/high-fanout concepts, oversized connected clusters, stale projects, missing next actions, broken relationships, deep folders, unused maps, repeated retrieval failures/unanswered topics, repeated ambiguity, weak provenance and stale current-state evidence.

Generated map/index/link/dashboard refresh is safe automation. Meaning-changing merge/move/archive/split/rename/hierarchy changes are review-gated. Advisory proposals include reason, evidence, affected objects/files, expected retrieval benefit, risks and rollback procedure, and cannot be auto-approved into a no-op canonical mutation. No automatic canonical deletion is allowed.
