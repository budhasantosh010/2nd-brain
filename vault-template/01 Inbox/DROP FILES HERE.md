# Drop Files Here

Drop unsorted files directly into `01 Inbox` or entire folders into `Folder Imports`.

You do **not** need to pre-tag, rename, classify, backlink, or manually choose a project. The ingestion engine preserves original bytes first, then extracts, indexes, and optionally compiles knowledge.

Unknown imports are private/local-only by default. Source text is treated as untrusted data and cannot override `AGENTS.md` or `10 System` policy.
