## Ask / AI instructions

When using an AI client, ask it to read `AGENTS.md` first and use the brain retrieval tools where available. Examples:

- `Process my Inbox.`
- `What do I know about X?`
- `Resume Project Y.`
- `Update the handoff for Project Z.`

The expected behavior is: **search → retrieve → verify → answer**, not model-memory guessing.
